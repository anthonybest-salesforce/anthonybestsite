## 7. Miss Pattern Analysis

### Identified Misses
1. **Long pull** — ball starts and stays left, full distance
2. **Weak cut** — ball starts slightly right, fades with reduced distance
3. **Thin / low on face** — low trajectory, reduced spin, excessive roll

### Root Cause Hypothesis
All three misses share a common mechanism: **inconsistent shaft behavior through the impact zone.**

The Recoil Dart 94g at 87 mph (top of its speed range) produces variable tip kick timing:
- Early release → face closes → **pull**
- Late release / held off → face stays open → **weak cut**
- Inconsistent arc bottom / shaft kick → contact point moves down face → **thin**

Low spin (5,500 rpm) is consistent with both:
- Excessive forward shaft lean stripping dynamic loft (shaft mechanism)
- Consistent low-on-face contact (gear effect — mechanical)

**Key unresolved question:** Is the thin miss / low spin primarily a shaft instability issue or a swing mechanics issue (early extension, shallow AoA)? This must be answered with launch monitor data before committing to the shaft change.

## 11. Data Collection Protocol

### Priority session: Outdoor range, real Pro V1 Left Dots
This is the gold standard. Indoor with Mevo+ is secondary.

### Indoor Mevo+ session requirements
- Metallic dots applied to range balls (Anthony has these)
- Indoor mode enabled in FlightScope app

- Replace metallic dots every 3–4 shots

### Clubs and shot counts
| Club | Shots | Purpose |
|---|---|---|
| 7-iron | 20 minimum | Primary anchor — all key metrics |
| PW (44°) | 15 | Confirm 1025E smash/spin vs Chromoly |

| 5-iron | 12 | Long iron spin profile, LP/MP boundary data |
| Driver | 10 | Explain low driver/iron speed ratio |
| 48° | 8 | Validate 115 total anecdotal |

### Metrics to record every shot (Mevo+ premium)
- Club speed
- Ball speed
- Smash factor
- Carry distance
- Total distance
- Launch angle
- Backspin
- Side spin / spin axis
- Apex height
- Descent angle
- Club path
- Face angle at impact
- Face to path
- Angle of attack

### Key diagnostic thresholds

**If any of these are true — shaft case weakens:**
- AoA shallower than −1° → thin miss is mechanical, not shaft-related
- Real Pro V1 spin on 7i is 6,200+ rpm → range ball was suppressing the number
- Smash factor consistently 1.32+ → contact quality is not the problem
- Face-to-path spread across 20 shots is < 3° → face timing is actually consistent

**If all of these are true — shaft case strengthens:**
- Spin stays below 5,800 rpm with real Pro V1
- Smash factor remains below 1.30 consistently
- Descent angle is below 40°
- Face-to-path spread > 3° shot-to-shot
- AoA is between −3° and −5° (correct mechanics, still losing spin)

### 7-iron shot tagging protocol
For each of the 20 shots, note:
1. Felt contact location (center / low / toe / heel)
2. Miss shape (straight / pull / cut)
3. Then cross-reference against Mevo+ data

This allows correlation of felt contact against spin, smash, and AoA — the critical diagnostic link.
