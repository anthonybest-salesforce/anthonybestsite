### Root Cause Hypothesis (Revised with LM Data)

The miss pattern is **not** a trajectory problem — descent angle averages 43.2° (in optimal range), roll-out averages 2.3 yards (low), and carry averages 169.1 yards (appropriate for 84.3 mph). 

The miss pattern is **high variance**: a 27-yard carry spread, 3,286 rpm spin spread, 0.19 smash spread, and consistent 4.8° out-to-in club path with variable face timing (FTP dev 2.3°) point to **inconsistent shaft behavior through the impact zone**.

The Recoil Dart 94g at 84–87 mph (ceiling of its designed range) produces variable tip kick timing:
- Inconsistent impact location (spread from low face to center) → wide smash variation (1.25–1.44)
- Variable shaft tip loading → variable spin (3,577–6,863 rpm in 15 shots)
- Variable face-angle timing relative to club path → fades and occasional pulls

The high variance is consistent with a shaft operating at its speed range boundary on every swing — the stabilized tip is at its limit, producing unreliable face-angle control.

**Prior narrative revision:** The working hypothesis of "shallow descent + excessive roll" was built on range-ball spin estimates (5,500 rpm assumed on anecdotal 145-yard carry). Actual LM data (43.2° descent, 2.3-yard roll-out, 169.1-yard carry) contradicts this. The real problem is not average trajectory — it's the 984 rpm spin variance (17% of mean) across 15 consecutive shots from the same club.

### Metrics to record every shot (Mevo+ premium)
- Club speed
- Ball speed
- Smash factor
- Carry distance
- Total distance
- Launch angle
- Backspin
- Side spin / spin axis
- Apex height
- Descent angle
- Club path
- Face angle at impact
- Face to path
- Angle of attack

### Key diagnostic thresholds

**If any of these are true — shaft case weakens:**
- AoA shallower than −1° → thin miss is mechanical, not shaft-related
- Real Pro V1 spin on 7i is 6,200+ rpm → range ball was suppressing the number
- Smash factor consistently 1.32+ → contact quality is not the problem
- Face-to-path spread across 20 shots is < 3° → face timing is actually consistent

**If all of these are true — shaft case strengthens:**
- Spin stays below 5,800 rpm with real Pro V1
- Smash factor remains below 1.30 consistently
- Descent angle is below 40°
- Face-to-path spread > 3° shot-to-shot
- AoA is between −3° and −5° (correct mechanics, still losing spin)

### 7-iron shot tagging protocol
For each of the 20 shots, note:
1. Felt contact location (center / low / toe / heel)
2. Miss shape (straight / pull / cut)
3. Then cross-reference against Mevo+ data

This allows correlation of felt contact against spin, smash, and AoA — the critical diagnostic link.
